# 指标、统计与分析口径

所有比例均保存分子、分母和参与 task/event IDs。零分母记 null，不记 0 或 100%。先定义，再运行。

## 1. 主指标

**最终任务成功率** = 当前运行选定 final skill 在固定测试集通过数 / 有效计划测试题数。数据/环境异常不能悄悄从分母删除；按预设协议重试或将该格判为未完成/无效。目标模型的真实任务失败与基础设施失败必须分开。

报告每 seed 成绩、均值与标准差、同 seed 方法差值，以及逐题胜/负/平。主要比较预注册为 full−core_00；full−repair_only、full−memory_only 为次要比较，外部对照为整体比较。

## 2. 固定重现修复与退化

每 seed 的 40 个重现任务由实验计划确定，所有方法相同。修复率 = 初次失败且重现通过数 / 初次失败数；退化率 = 初次通过且重现失败数 / 初次通过数。

各 arm 的初次失败集合可能不同，所以各自比例只作描述。另报告所有方法共同任务上的配对状态转移、共同失败子集（若非空）的修复情况；不能把更容易的错题集合误认成更好的修复能力。执行用的 current skill 与最终 best 不同则记录两者身份；固定重现不是最终测试结果。

## 3. 无提升失败保全

失败覆盖率 = 成功持久化的有效训练失败事件 / 全部有效训练失败事件；分别统计 skip_no_patch、Δselection=0、gate_reject、inconclusive。

M 开启时目标应为 100%。这是工程正确性，不是论文的主要质量收益。M 关闭组的影子审计日志只用于离线统计，不代表启用了 M。

持续未解决问题的再处理率 = 在后续有合格反思机会时再次被引用的问题数 / 有这种机会的未解决问题数。时间窗口、合格机会和冷却规则预先固定；运行末尾新发现的题不能与有五轮机会的题直接比较。

## 4. 修复提案质量

- 来源可验证率：证据引用真实且来自允许训练范围的提案 / 全部提案。
- 可应用率：精确锚点、版本和 patch 编译通过 / 全部提案。
- 重复无效提案率：有先前明确未解决观测、仍提出相同规则目标/操作/内容且没有新证据的提案 / 有历史可比较机会的提案。先报告精确重复；语义近重复用固定抽样盲审，不只用提出者模型自评。
- 有效修改率：候选后观测到目标训练行为/结果改善的尝试 / 有可比较后续训练证据的尝试。缺证据记 unknown，不能当失败或成功；这个指标不提供单条编辑因果证明。

可抽 40 条完整系统提案和 40 条对照提案（按预先 seed 抽样），隐藏方法名审查“引用是否支持诊断、动作是否可验证、是否过拟合单题”。记录评分规则、无法判断比例与审查者分歧。

## 5. 成本

分别计：task executions、逻辑模型调用、实际 HTTP 尝试、缓存命中、输入/输出/reasoning tokens、错误/重试次数、训练与最终测试 wall time、skill 字符数与固定 tokenizer 下 token 数。

价格只在运行时可核验时估算。历史“免费”不等于当前免费；没有完整 usage 的 API 要报告 coverage，不能把缺失写成零。

## 6. R/M 交互与不确定性

每 seed 定义交互描述量 I = score11 − score10 − score01 + score00。三个 seed 分别报告，不因 I>0 就宣称统计上证实协同。

训练 seed n=3，统计功效有限。任务配对 bootstrap 可描述条件于这些已训练 skill 的任务不确定性；若做 seed/task 两层重采样，仍必须强调三个 seed 的有限性。禁止把 3×120 当作 360 个独立任务以缩窄区间。

约 120 个测试任务通常难以可靠区分很小的提升。不要预先保证显著、不以测试 p 值反向增加 seed。多项次要比较需要相应多重比较说明，不能挑显著者作为唯一结论。

最终失败分析也应覆盖无收益/退化。冻结后不调阈值或预算；探索性分析与预注册主比较分开标注。
