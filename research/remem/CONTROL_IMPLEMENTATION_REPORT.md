# 外部对照与公共限额实施记录

2026-10-24。当前为开发验收阶段，正式实验未运行。

- 原生 SkillOpt 与 CAM 接入同一训练器和任务审计，保留原生跨步历史；核心 R/M 消融仍不接收这些历史。
- CAM 是本地已记录快照的六个机制模块移植，保留许可证。来源和移植后哈希见 `cam_port_provenance.json`；不是旧 CAM 整仓或原历史运行的精确复刻。与当前 SkillOpt 上游复用的边界是原生反思/聚合/排序/执行器；CAM 只增加证据预算、持久记忆、配对选择、软接受、分组保护与漂移恢复。
- CAM 原最大编辑预算 4，本比较共同上限 2；最少支持任务 2、非劣界 .05、组退化界 .10、组最少 5 题、漂移 patience 2、词面检索阈值 .15、半衰期 8，均显式冻结。小面板可能不满足分组检查最少题数，不能据此证明分组保护有效。
- AtomSearch 使用独立搜索执行器，共享模型配置、数据适配器、执行日志和调用限额。来源、假设及验收见 `docs/remem/12_ATOMSEARCH.md`。
- 优化器限额覆盖反思、聚合、排序等阶段，线程间共享并持久化；HTTP 重试单独计数；缺用量仍为缺失。优化器未完成调用和辅助阶段错误禁止静默继续。
- `train_size` 表示唯一训练池大小，任务序列表示实际训练次数；不再通过把唯一池大小写成 120 来模拟六步。

离线测试与真实预实验结果将分别记录。旧开发冻结包保留；当前源码改变后不能沿用旧包执行。

2026-10-25：真实联调发现并修复密钥加载后模块内存未刷新问题；鉴权错误不再重试。CAM 原格式含验证任务 ID，本移植将它们从模型可见记忆中删除，保留离线审计和聚合支持数量。AtomSearch 全失败训练批次改为显式无对比证据，不调用模型生成不可能满足的提案。新增完整逻辑调用耗时；旧版本只有整轮耗时和 HTTP 响应头耗时，不补造缺失的逐调用完整耗时。
